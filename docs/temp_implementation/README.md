# Área Temporária de Trabalho - Revisão e Validação do CEH

Esta pasta contém os artefatos de trabalho da revisão técnica, validação empírica do Conselho de Seniores e desenho de implementação do **CLEARER Engineering Harness (CEH)**.

## Estrutura de Diretórios

* `evidence/`: Registros de saída brutos, saídas JSON e artefatos de teste isolados comprovando cada achado (R1 a R10).
* `scripts/`: Scripts auxiliares e harnesses de reprodução isolada desenvolvidos para executar os dry-runs sem efeitos colaterais.
* `handoffs/`: Relatórios versionados de handoff documentando a evolução do entendimento, experimentos, análises e propostas de solução.

## Ciclo de Vida

Conforme as diretrizes de governança do CEH, estes arquivos são preservados durante as etapas de análise, reprodução e implementação, servindo como trilha de auditoria para o Conselho de Seniores.
